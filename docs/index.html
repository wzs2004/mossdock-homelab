Audiobookshelf 工具箱 三合一

转写管理 · 书籍元数据匹配 · Language Reactor 桥接，一个扩展全包。

从 Chrome 应用商店安装 下载 zip（本地安装） 查看源码

① 转写管理

书库首页看转写队列（排队 / 进行中 / 完成 / 失败），进书一键开始或重试，实时看进度和报错，完成后直接搜 SRT。

② 书籍元数据匹配

在书籍页列出全部候选来源，对比标题/作者/封面/简介，挑一个一键套用，也可以只改其中几项。

③ Language Reactor 桥接

把单条音轨连同已有 SRT 字幕送进 Language Reactor；隧道卡住会给超时提示和「重试」。

安装方式一：Chrome 应用商店（推荐）

  1. 点上面的「从 Chrome 应用商店安装」（审核通过后才可访问）
  2. 点「添加至 Chrome」
  3. 扩展选项里填三个密钥（见下）

安装方式二：本地加载（控制台审核期间也能用）

  1. 双击 install-macos.command（首次右键 → 打开），它会把 zip 解压到 ~/Downloads/AudiobookshelfPlugins/toolkit
  2. Chrome 打开 chrome://extensions，右上角开启 开发者模式
  3. 点「加载已解压的扩展程序」，选那个 toolkit 文件夹
安装后点扩展图标打开设置，填三项密钥（都只存在本机浏览器）：
• 转写服务密钥 X-ASR-Extension-Token（stacks/transcription-manager/.env）
• 元数据服务密钥 X-Meta-Token（stacks/meta-bridge/.env）
• 桥接服务密钥 X-LR-Bridge-Key（stacks/lr-bridge/.env）
服务器地址只需填一个域名，三个服务路径自动推导（/__ext/asr、/__ext/meta、/__ext/lr）。
Chrome 137 起禁止商店外静默安装扩展，所以本地加载必须手动拖文件夹；脚本已经把下载、解压、打开扩展页都做完了。换域名后重新下载一次 zip 即可。
