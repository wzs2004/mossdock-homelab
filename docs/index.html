书籍匹配

在书籍页选择元数据来源，查看全部候选并一键应用。

转写管理

管理 Whisper 任务、SRT 字幕、章节和文稿。

Language Reactor

把单条音轨连同字幕送进 Language Reactor。

安装步骤

  1. 下载并双击 install-macos.command（首次右键 → 打开）
  2. Chrome 打开 chrome://extensions，右上角开启 开发者模式
  3. 把 ~/Downloads/AudiobookshelfPlugins/ 里的三个文件夹拖进页面
  4. 打开每个扩展的「选项」，填入服务器地址和密钥
Chrome 137 起禁止从商店外静默安装扩展，所以最后一步需要手动拖入文件夹；脚本已经把下载、解压、打开页面都做完了。
