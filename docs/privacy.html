隐私权政策

适用于本仓库发布的 Chrome 扩展：转写管理、书籍元数据匹配、Language Reactor 桥接
Last updated / 最后更新：2026-11-14

一句话：扩展只在你的浏览器和你自己的服务器之间传数据，开发者不收集、不接收、不转卖任何数据。

1. 扩展做什么

这三个扩展是自托管 Audiobookshelf（有声书服务器）的辅助工具，用来查看转写队列、匹配书籍元数据、把音轨和字幕送进 Language Reactor。它们只在你当前打开的网页上工作。

2. 我们收集什么

什么都不收集。扩展没有埋点、没有统计、没有崩溃上报，也不会把任何数据发送给开发者或第三方服务器。

3. 数据存在哪

服务器地址、访问令牌、你填写的偏好设置，都存在你自己的浏览器里（chrome.storage / localStorage），不离开本机。卸载扩展即删除。

4. 数据发给谁

只有两个目的地：

  • 你自己配置的 Audiobookshelf 服务器（域名由你在扩展选项页填写，默认是你的自建实例）；
  • languagereactor.com —— 仅在你点击「发送到 Language Reactor」时，把该条音轨的地址和字幕交给该网站（与你手动粘贴链接效果相同）。

除此之外不会向任何域名发起请求。

5. 权限说明

扩展请求的权限只用于访问上述服务器和页面（例如读取书库页面、在页面里注入按钮）。不读取与 Audiobookshelf 无关的网页内容。

6. 儿童隐私

扩展不面向 13 岁以下儿童，也不收集任何年龄信息。

7. 变更

本政策更新会提交在本仓库，页面顶部保留更新日期。

8. 联系方式

问题、数据删除请求：github.com/wzs2004/mossdock-homelab/issues
